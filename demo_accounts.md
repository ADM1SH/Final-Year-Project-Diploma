### 🚀 Quick Start Instructions
1. **Start Backend:** `python manage.py runserver 0.0.0.0:8000`
2. **Start Mobile:** `npx expo start` (Use `--tunnel` if on separate networks)
3. **Reset Data:** If needed, run `python seed.py` to refresh all accounts and listings.
